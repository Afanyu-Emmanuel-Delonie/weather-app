# Session 6 – Firebase Auth, Firestore & Live Location Weather

A Kigali Weather app upgraded with Firebase Authentication, Cloud Firestore logging,
and live GPS-based weather using the Open-Meteo API.

## What's New in Session 6

- Firebase Authentication (email/password sign-in and sign-up)
- AuthGate routing — auto-redirects based on login state
- Cloud Firestore — logs every weather fetch under the user's UID
- Live GPS location — weather is fetched for wherever you actually are
- Last 5 fetches displayed live via Firestore StreamBuilder

    providers/weather_api.dart      # WeatherApi provider wrapper

## How It Works

### Auth Flow
```
App start
  └── AuthGate (StreamBuilder on authStateChanges)
        ├── not logged in  →  LoginScreen
        └── logged in      →  WeatherHomeScreen
```

### Weather Flow
```
WeatherHomeScreen loads
  └── shows cached weather instantly (shared_preferences)
  └── requests GPS permission
  └── gets current position
  └── fetches live weather from Open-Meteo API
  └── saves to shared_preferences (offline fallback)
  └── logs to Firestore: users/{uid}/weather_logs
  └── StreamBuilder shows last 5 fetches live
```

### Firestore Data Structure
```
users/
  {uid}/
    weather_logs/
      {docId}/
        temperature   : number
        feelsLike     : number
        humidity      : number
        windSpeed     : number
        weatherCode   : number
        isDay         : boolean
        lat           : number
        lon           : number
        fetchedAt     : timestamp
```
